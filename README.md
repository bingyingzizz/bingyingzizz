### 数学星图 MathGalaxy

把数学概念按依赖关系画成一张可漫游的星图 —— **9 个星系 / 45 个星团 / 709 个节点 / 1398 条连线**，
从 ZF 公理一路到凝聚态数学。每个概念一个节点、一份独立网页，推导的证明写在边上。

**[🔭 在线浏览](https://bingyingzizz.github.io/mathgalaxy/)** ·
**[📦 源码](https://github.com/bingyingzizz/MathGalaxy)**

纯静态、零依赖：双击 `index.html` 就能跑，不用装任何东西。
图上的四种边 —— 黑箭头 = 推出 · 黑直线 = 等价 · 蓝线 = 定义引用 · 紫虚线 = 跨领域类比（弱边）。

也留了给 AI 的入口：`dist/graph.json`（机器可读全量）、`dist/graph.md`、
[`llms.txt`](https://github.com/bingyingzizz/MathGalaxy/blob/main/llms.txt)（检索协议）。

方向上偏本科以上的数学：集合论 · 序理论 · 拓扑 · 抽象代数 · 分析 · 范畴论 · 同调代数 · 凝聚态数学。
